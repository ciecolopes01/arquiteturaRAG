Como os Serviços se Conectam em Produção

Todos os serviços orquestrados via Docker Compose, com isolamento e tolerância a falhas.

Qdrant Vector DB Porta 6333

Armazena vetores densos de 1024 dimensões com HNSW otimizado e payload com metadados de ACL.

PostgreSQL 16 Porta 5432

Catálogo canônico, índice de busca léxica BM25 (`tsvector`), integridade referencial e auditoria.

Neo4j 5 Graph DB Portas 7474 / 7687

Base de conhecimento em grafo: nós de entidades, triplas semânticas e relações interconectadas.

Redis 7 Porta 6379

Cache de alta performance para embeddings pré-calculados e respostas com TTL inteligente.

MinIO (S3) Portas 9000 / 9001

Armazenamento de objetos compatível com AWS S3 para PDFs, áudios, vídeos e imagens originais.

Claude 3.5 Sonnet Anthropic API

Síntese de respostas aumentadas por contexto, validação de auto-avaliação e visão multimodal.
